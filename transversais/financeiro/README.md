# Transversais — financeiro

Área transversal de financeiro (corta todas as frentes). Overview de alto nível apenas.
Assuntos estratégicos confidenciais (estruturação jurídico-tributária, veículos de
remuneração) **não** se registram em arquivo — só em conversa.

## Ferramentas

- [`../../ferramentas/despesas/`](../../ferramentas/despesas/) — **Prestação de contas**:
  lançamento de despesas de viagem e sede com foto do comprovante, fechamento mensal,
  PDF para reembolso e consolidação da equipe por export/import JSON.
  Contrato de dados: `ferramentas/despesas/despesa.schema.json` (valores em centavos).
  Arquitetura **local-first** — os dados ficam no aparelho de cada pessoa, não em servidor.
